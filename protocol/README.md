# Protocol

Jetson 通过 USART3 向 STM32 发送单行 ASCII 运动指令：

```text
<direction>,<speed>\n
```

- `direction`：`F` 前进、`B` 后退、`L` 原地左转、`R` 原地右转、`S` 停止。
- `speed`：十进制整数，范围为 `0`～`100`。

示例：

```text
F,20
S,0
```

STM32 成功解析并执行后返回 `A\n`，无效指令返回 `E\n`。当前串口配置为 115200 波特率、8 数据位、无校验、1 停止位。

Jetson 在目标跟踪期间约每 0.3 秒重复发送指令；STM32 连续 1.2 秒没有收到有效指令时自动停止底盘。

当前基线面向 X 型麦克纳姆轮底盘，但只使用前进、后退和原地旋转能力。横向速度与完整麦克纳姆运动学将在后续协议版本中加入。
