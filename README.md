# embodied-robot-heterogeneous-control
This work presents a wheeled‑robot system built on Jetson Orin Nano‑STM32 heterogeneous computing architecture. It performs asynchronous VLA inference and hard real‑time motion control, decoupling high‑level AI decision‑making from low‑level motor control to address motion stuttering and poor real‑time performance for edge embodied intelligence.
